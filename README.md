面向香港高级 iOS 岗位的 5–6 周面试准备资料。当前以文档、口述练习和真实项目案例为主，不依赖已删除的旧网页题库文件。

## 推荐学习顺序

1. `简历项目深挖题.md`：先练三个真实案例。
2. `iOS系统与UIKit高频面试题.md`：补齐高级 iOS 主体能力。
3. `OC高级面试题.md`：恢复 Objective-C 核心知识。
4. `OC开发者Swift速查.md`：手写 Swift 基础和 UIKit 网络小练习。
5. `Swift-UIKit练习项目任务书.md`：完成 7–10 天无 AI 首写项目。
6. `Swift高级面试题.md`：只按文件顶部的 P0 → P1 顺序学习。
7. `粤语行为面试与英文最低脚本.md`：准备招聘电话、行为面试和英文最低沟通。

## 每日使用方式

- 45 分钟：无 AI 首写 Swift。
- 45 分钟：随机抽 5 道技术题，用粤语回答。
- 30 分钟：项目案例、简历或真实投递复盘。

每道题先答 30 秒结论，再答 90 秒完整版本。没有真实项目证据时，只讲机制和练习项目，不编造生产经验。

## 投递与复盘

- 第 2 周开始试水投递，不等全部材料背完。
- 每次面试后记录原题、追问、卡住原因和正确答案。
- 强制算法轮不纳入当前准备范围。
- 永久职位优先；条款清晰的一年以上合约岗可作为备选。
